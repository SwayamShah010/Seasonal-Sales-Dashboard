# Seasonal Sales & Regional Performance Dashboard

An end-to-end analytics project for a **seasonal, high-volume consumer durables business** (air conditioners, air coolers, refrigerators, washing machines). It turns messy sales, channel, target, inventory and service data into a Power BI dashboard and an automated Excel MIS report.

> **Data note:** all data is **synthetic**, generated by `scripts/generate_data.py` with a fixed random seed. It is not real company data. Seasonality, regional weights and targets are built into the generator, so the insights below illustrate what the dashboard surfaces, not real-world findings.

## What this project covers

| Area | What was done | Where |
|---|---|---|
| Data cleaning and validation | pandas pipeline: deduplication, mixed date-format parsing, region label standardisation, missing/negative/outlier handling, imputation with audit log | `scripts/clean_data.py` |
| Power Query | M scripts for typing, date parsing and cleaning raw sales | `powerbi/power_query_m.md` |
| Data modelling | Star schema: sales, targets, inventory and service facts joined to date, product, dealer, region and category dimensions | `powerbi/dashboard_build_guide.md` |
| DAX | 25+ measures: achievement %, YoY, YTD, rolling 3M, seasonality index, peak-season share, sell-through, months of cover, service KPIs | `powerbi/DAX_measures.md` |
| SQL | 8 analysis queries (CTEs, window functions `LAG`/`RANK`, conditional aggregation) on SQLite | `sql/analysis_queries.sql` |
| Report automation | Python script that builds a formatted multi-sheet Excel MIS report | `scripts/generate_mis_report.py` |
| Testing | Pytest tests for cleaning rules and output integrity | `tests/` |

## Dashboard pages
1. **Executive Overview**: KPIs, trend by category, achievement by region
2. **Seasonality and Demand**: monthly pattern, seasonality heatmap, peak-season share
3. **Target vs Achievement**: region and category matrix with RAG status and gaps
4. **Channel, Inventory and Service**: primary/secondary/tertiary movement, months of cover, ticket performance

## Dataset (synthetic)
- 2 years (Jan 2024 to Dec 2025), 4 regions, 16 states, 48 dealers, 7 products in 5 categories
- Sales at three channel levels: **Primary** (company to distributor), **Secondary** (distributor to dealer), **Tertiary** (dealer to customer)
- Monthly targets by region and category, month-end inventory snapshots, service tickets
- Raw sales deliberately contain: ~200 duplicate rows, 3 date formats, region typos (`NORTH `, `north zone`), missing units/values, negative units and extreme outliers

## Example insights from the synthetic data
- Tertiary (retail) volume grew about **11% YoY** (7,390 to 8,196 units).
- About **70% of annual cooling-product units** (ACs and coolers) sell in **Mar to Jun**; air coolers peak in April, ACs in May.
- **North** is the largest region (about 31% of units) but **under-delivers target (about 97%)**, while West and South are at or just above target. Air coolers are the weakest category against target (about 96%).
- Channel pipeline in 2025: 13.0k primary, 9.7k secondary and 8.2k tertiary units, a sign of stock building up in the channel.

## How to run
```bash
pip install -r requirements.txt
python scripts/generate_data.py        # creates data/raw/*.csv
python scripts/clean_data.py           # creates data/clean/*.csv + data quality log
python scripts/generate_mis_report.py 2025-12   # creates reports/MIS_Report_2025-12.xlsx
python scripts/load_to_sqlite.py       # creates data/sales.db for sql/analysis_queries.sql
pytest tests -v
```
Then follow `powerbi/dashboard_build_guide.md` to build the Power BI report from `data/clean/`.
